# MW4 / Warzone / DMZ sources (self-expanding list)

User order 24.11.2026: "Erweitere auch deine Quellen selbstständig. Du musst immer besser werden in allen Bereichen".
Rules: official first. A fact is usable if it comes from Tier 1, or from 2 independent Tier 2 sources. Leaks/datamines/rumours never.
Every run that finds a useful new source adds it under "Candidates" with date + what it was good for. The weekly task "Reichweiten-Optimierung" promotes or drops candidates (promote after 3 correct uses that matched Tier 1 / other Tier 2; drop on 1 clear error).

## Tier 1 – official (fact)
- callofduty.com blog + official patch notes (MW4, Warzone, DMZ)
- Official Call of Duty socials (main account + updates account)
- Activision Support (known issues, server status)
- In-game info when shown in official media (screenshots/trailers from Activision)

## Tier 2 – trusted (2 sources needed)
- codmunity.gg – build codes, attachments, weapon levels, pick rates (main build source)
- warzoneloadout.games – second build source / cross-check
- Dexerto – news, build round-ups
- CharlieIntel – news, patch summaries
- Dot Esports – guides, settings
- Game Rant – guides
- MW4 Intel – tier lists
- Digital Foundry – graphics/performance only
- Creator builds (only with credit, cross-checked): JustHazzardous, Astroboost
