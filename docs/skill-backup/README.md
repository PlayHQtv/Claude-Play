# Skill backup (anonymized)
An anonymized copy of the Claude skill with the rules and workflow for our TikTok account.
It is updated after every skill change, so the knowledge survives even if chats are deleted.
The repo is public, so `anonymize.py` replaces account IDs, cloud names, trigger IDs, post UUIDs, OpusClip project and clip IDs,
our own handle and e-mails with placeholders (<METRICOOL_BLOG_ID>, <CLIP_ID>, ...).
To restore: propose a new skill from this file and fill the placeholders from Metricool, OpusClip and Cloudinary.
